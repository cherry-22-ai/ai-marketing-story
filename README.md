# 老板别慌，这局我来

一部可交互的AI营销与产品运营作品。围绕一家小店，展示经营任务拆解、内容表达、视频模板复用、质量检查与反馈迭代。

包含6条真实视频案例、本人及AI的工作分工、迭代对照与完整8页调研报告。主线约2分45秒，片尾可选工作日下午支线。菜单替换环节为结构与检查示范，不现场生成新视频。

## 打开与部署

入口为根目录小写 `index.html`。所有素材与脚本均放在根目录，上传时请保留全部文件名。

GitHub Pages：Settings → Pages → Deploy from a branch → main → /(root) → Save。

手机打开后点击“开始故事”，按需开启声音。可以选择任务、查看六条作品、产品复盘及调研报告。

配乐署名与许可证见网页页脚；引擎和字体许可证保留于HTML内。
