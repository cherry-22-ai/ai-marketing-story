# 老板别慌，这局我来

[打开互动作品](https://cherry-22-ai.github.io/ai-marketing-story/)

一部可交互的 AI 营销与产品运营作品：从商家任务出发，展示内容表达、视频模板复用、质量检查与反馈迭代。

包含六条真实视频案例、本人及 AI 的工作分工、修改前后对照与完整八页调研报告。主线约两分四十五秒，片尾可继续工作日下午支线。

## 文件结构

```text
index.html              网页入口
README.md               项目说明与维护方法
.nojekyll               直接发布静态文件
assets/
  css/                  网页样式与字体声明
  js/                   播放器、故事、动画与案例配置
  images/               角色、场景、案例封面与报告页面
  audio/                背景音乐
  fonts/                网页字体
  videos/
    playback/           默认使用的轻量播放版
    originals/          可切换查看的高清原片及对照素材
```

素材名中的短编码用于区分文件版本；脚本采用用途明确的名称，例如 `player.js`、`media.js`、`content.js`。

## 后续更新

1. 修改并预览作品，生成新版发布文件。
2. 将有改动的文件提交到本仓库的 `main` 分支，保留上述目录结构。
3. 替换素材时同步更新引用路径，不必重复上传未修改的素材。
4. 在 Actions 中确认 Pages 部署成功，再检查作品、案例、声音及调研报告。

发布配置：Settings → Pages → Deploy from a branch → main → /(root)。入口始终为根目录小写 `index.html`，分享链接保持不变。

六条案例默认使用轻量视频，并保留切换高清原片入口。手机点击“开始故事”后按需开启声音。菜单替换环节为模板结构与校验点示范，不现场生成新视频。

配乐署名与许可证见网页页脚；引擎和字体许可证保留在 HTML 内。
